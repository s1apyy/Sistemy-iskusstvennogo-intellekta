# Системы искусственного интеллекта (7 семестр)

Лабораторные работы по дисциплине «Системы искусственного интеллекта» (УлГТУ).

## Состав

| Лаба | Тема | Папка | Отчёт |
|------|------|-------|-------|
| ЛР1 | Классификация изображений (CNN, PyTorch) | `ЛР1_классификация/` | `Отчёты/ЛР1_Классификация.docx` |
| ЛР2 | Аугментация данных | `ЛР2_аугментация/` | `Отчёты/ЛР2_Аугментация.docx` |
| ЛР3 | Генерация текста (char-LSTM) | `ЛР3_генерация_текста/` | `Отчёты/ЛР3_Генерация_текста.docx` |
| ЛР4 | Сегментация изображений (U-Net) | `ЛР4_сегментация/` | `Отчёты/ЛР4_Сегментация.docx` |

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

### ЛР1
```bash
python ЛР1_классификация/download_dataset.py
python ЛР1_классификация/train.py
python ЛР1_классификация/visualize.py
```

### ЛР2
```bash
python ЛР2_аугментация/train_aug.py
```

### ЛР3
```bash
python ЛР3_генерация_текста/train_and_generate.py
```

### ЛР4
```bash
python ЛР4_сегментация/prepare_dataset.py
python ЛР4_сегментация/train_segmentation.py
```

Датасеты создаются скриптами и сохраняются в `datasets/` (папка в репозиторий не входит).
